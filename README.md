# AstrBot · NovelAI V5 绘图

在聊天中用中文描述画面，由插件的独立编词 Agent 读取随插件分发的 nai5-prompting 资料，编写主提示词、角色描述、角色中心坐标和按需使用的负面提示词。插件将这些字段提交至 NovelAI，解包 PNG 并作为图片消息发送。

## 安装与配置

1. 在 AstrBot WebUI 的插件管理页选择「从 URL 安装」，填入 `https://github.com/Zhuhui-02/astrbot_plugin_nai5`，也可上传插件 ZIP。也可以将包内的 `astrbot_plugin_nai5` 文件夹放到 AstrBot 的 `data/plugins/` 下，然后重启 AstrBot。图生图依赖 Pillow，已在 requirements.txt 声明。
2. 在插件设置「独立编词模型 Provider ID」中填写 AstrBot 已配置的文本模型提供商 ID。留空时复用当前会话选择的模型，每次编词仍使用全新的上下文。
3. 在插件配置中选择「生图服务商」，填写该站签发的密钥并保存。各站密钥独立，环境变量优先于对应配置字段。

   | 生图服务商 | 填写的密钥 | 可选环境变量 |
   | --- | --- | --- |
   | NovelAI 官方（默认） | NovelAI Persistent API Token | `NOVELAI_API_TOKEN` |
   | 蛋糕 | 在 dangao.iisbo.com 创建的 API Key | `DANGAO_API_KEY` |
   | Langbai | 在 nai.langbai.cc 控制台创建的 API Key | `LANGBAI_API_KEY` |
   | 自定义镜像 | 该站的 API Key，另填包含接口路径的完整 HTTPS 生图地址 | `NAI_MIRROR_API_KEY` |

   两个预设镜像都请求站点根域上的 `POST /ai/generate-image`，沿用 NovelAI 原生请求体、Bearer 鉴权和 V5 角色字段。文生图、图生图及重画使用当前选中的站点，费用由该站结算。自定义地址需支持同一协议和所选模型；定价页、OpenAI 的 `/v1` 地址不能用作原生生图地址。参见 [蛋糕站点](https://dangao.iisbo.com/) 和 [Langbai 接口文档](https://nai.langbai.cc/docs)。
4. 选择 V5 Full 或 V5 Curated，以及方形、横图或竖图。默认使用 V5 Full、1024 × 1024、28 步，每次生成一张。支持配置采样步数、提示词引导强度、图生图变化强度和噪声。绘图使用 Token 对应账户的额度。

## 在聊天中使用

**AI 复核提示词。** 默认开启。在自然语言绘图、`/nai`、`/nai预览` 和 `/nai图生图` 编词后，插件用同一编词模型开启新上下文，对照本条原文、选定预设和候选提示词。复核按文字描述检查，图生图的原图仍只发给生图服务。发现偏差会修订一次，再独立复核；仍有偏差或复核异常时会停在生图前。正常多一次文本模型调用，发生修订共多三次。`/nai确认`、`/nai重画` 和 `/nai原词` 沿用各自已有的词。复核检查提示词与需求是否一致，成图仍受图像模型影响。

**优先处理明确的绘图请求。** 在插件配置中开启「明确绘图请求优先处理」（新安装默认开启，升级沿用已保存的值）。唤醒机器人后，说「帮我画一张雨夜街景」或「用月白画风画一张雨夜街景」，插件会在聊天人格回复前，将本条消息的画面描述和选定预设直接送入编词流程。请在本条文字中写全画面要求。普通讨论继续走聊天流程。此设置只改变请求分发顺序，编词模型及生图服务自身的内容规则仍然适用。

**画风预设。** 在插件配置的「画风预设」中，每项填写 `名称｜画风说明`。例如 `绘本铅笔｜保留纸张纹理，以松散的彩铅排线表现阴影，暖灰色调`。新安装时预设列表为空，由你填写名称和原文。升级会保留原配置，旧版示例可在这里删除。把名称填入「默认画风名称」，即可应用到之后的 AI 编词请求。默认留空。

发送 `/nai画风` 可查看名称。添加上面的「绘本铅笔」后，直接说「用我的绘本铅笔画风画一家书店」。插件从本条消息识别预设名称，读取预设全文交给编词 Agent。也可用 `/nai预览 【画风：绘本铅笔】下雨天的书店门口` 查看提示词。单次指定只对本次生效，`【画风：无】` 可临时跳过默认画风。模型会同时读取场景、预设原文和技能的画风写法，据此编写提示词。文生图、图生图、预览和自然语言绘图均走这一流程。`/nai原词` 直接使用原文，确认和重画沿用已经编好的提示词。

**直接说出绘图需求。** 在已唤醒机器人的聊天中说「帮我画一张雨后街角的水彩画」。启用优先处理时，明确的绘图请求直接触发插件。其他说法可由已启用的 `nai5_draw_image` 工具触发。两种入口和预览均由同一个 Agent 编词，只接收本条用户原文、选用的画风和随包技能。请在本条消息写全角色和场景；“沿用刚才的人物”需补上人物描述。群聊按现有唤醒设置 @机器人即可。也可以用 `/nai 描述` 明确触发绘图。

**QQ 聊天记录卡片。** 使用 OneBot v11（aiocqhttp）接入 QQ 时，群聊和私聊默认把成图和种子装入一条合并转发消息，点开「聊天记录」即可看图。此设置适用于全部出图入口。在插件配置中关闭「QQ 用聊天记录卡片发送成图」即可切换至普通图片。其他适配器使用普通图片。卡片需要 OneBot 实现支持所在聊天类型的合并转发。实现参考 [ppnai 的绘图回复](https://github.com/dafeiwu666/astrbot_plugin_ppnai/blob/main/src/handlers_nai.py)。

| 指令 | 效果 |
| --- | --- |
| `/nai 雨后的东京小巷，穿黄色雨衣的女孩从蓝色自动售货机旁走过` | 直接编写提示词并出图 |
| `/nai预览 横向构图，左侧银发女孩把红伞递给右侧黑发少年` | 调用聊天模型，显示主提示词、角色栏和位置 |
| `/nai上次提示词` | 查看本人在当前会话最近一次成功文生图的编词来源和实际使用的主提示词、角色栏、坐标、负面词及种子，可与图片上的种子核对。查询不调用模型 |
| `/nai确认` | 每次用本人在当前会话的最近预览生成一张图，可重复确认，无需重新编词 |
| `/nai图生图 将街景改成雨夜水彩画` | 随指令附一张原图，或回复平台能解析出图片的消息。插件将原图居中裁切到配置画幅后交给 NovelAI，聊天模型只读取文字描述 |
| `/nai原词 watercolor, rainy street` | 将已有主提示词直接提交给 NovelAI，无需聊天模型 |
| `/nai重画` 或 `/nai重画 42` | 复用本人在当前会话最近一次成功文生图的提示词和参数，随机或指定种子。每次出图会回传本次种子 |
| `/nai帮助` | 查看指令示例 |

**编词报错时**，发送 `/nai预览 一只白猫坐在窗台上` 即可单独检查聊天模型。插件能直接读取带前后说明的 JSON。若模型按技能示例返回 Markdown 分栏等格式，插件会请同一个聊天模型整理一次，可能多用一次聊天额度。仍然失败时，回复会标出空正文、JSON 语法或具体字段问题。只有取得可用提示词后，绘图指令才请求生图服务。

预览有效期为 10 分钟，从预览成功时开始计时。在有效期内可多次发送 `/nai确认`，每次沿用同一份提示词并随机取种子。新的成功预览会替换本人在当前会话的旧预览。插件重载会清除预览和重画记录。账户按实际生成结算，遇到超时可先核对用量。提示词里的构图用语指导画面内容，输出像素尺寸由插件画幅配置决定。多人共享机器人的场合，可在 AstrBot 的命令权限管理中设置使用范围。

本版的图生图、重画和参数设置参考了 [xxuanzQAQ 的 AstrBot NovelAI 插件](https://github.com/xxuanzQAQ/astrbot_plugin_novelai)。

## 随包技能及来源

内置 Miint-Sunny 的 v1.2.9 完整拆分包，共 11 个技能。原文、参考文件、许可与署名位于 `vendor/nai5-prompting/`。绘图入口默认读取构图、字段职责、质量词、角色栏和主串顺序；遇到漫画、四格、服装等关键词时追加对应写法。插件直接读取本地章节并传给聊天模型，安装后即可使用。技能原文保留上游的 GPL-3.0-only 许可与第三方材料声明，插件代码采用 GPL-3.0-only。固定来源见 [上游版本快照](https://github.com/Miint-Sunny/nai5-prompting/tree/a5f3df8eaafe0f4563f64d6165e34c9aa112abb7)。

AstrBot 的会话模型查找和生成接口见 [AstrBot 插件 AI 指南](https://docs.astrbot.app/dev/star/guides/ai.html)。生图使用 Bearer Token 和官方图像域名上的 POST /ai/generate-image，并请求 ZIP 响应。接口与模型说明见 [NovelAI 图像 API](https://image.novelai.net/docs/doc.json) 和 [官方模型文档](https://docs.novelai.net/en/image/models/)。V5 参数及角色字段同时参考了 [NAIWeaver 的请求构造代码](https://github.com/ststoryweaver/NAIWeaver/blob/master/lib/core/services/nai_request_builder.dart)。
